# Co-op Construction

A Roblox co-op construction game: a crew of 2–6 players, each in a real trade, builds a house on a ghost blueprint
before the deadline while things go wrong, then gets paid and upgrades.

- `src/` mirrors the Studio place (ReplicatedStorage, ServerScriptService, ServerStorage, StarterPlayer) one to one,
  so Rojo can be added later without moving anything. The code lives in the place; these files are kept in sync with it.
- `PLAN.md` is the design doc, `design/` holds the job and town plans.
- `CLAUDE.md` has the game rules, coding rules and a log of everything that was built and tested.
